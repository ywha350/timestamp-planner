# 플래너

배포 주소: https://ywha350.github.io/timestamp-planner/

main 브랜치에 push하면 GitHub Actions가 테스트와 빌드를 실행하고 GitHub Pages에 배포합니다. HTTPS 주소를 Safari에서 열고 홈 화면에 추가하면 PWA로 사용할 수 있습니다. 로컬 주소에 저장한 데이터는 배포 주소로 자동 이전되지 않습니다.

Vite 기반의 모바일 PWA. 화면에는 시간, 소요 시간, 할 일 텍스트만 표시합니다. 계획은 IndexedDB에 자동 저장되며 최초 접속 후 오프라인으로 사용할 수 있습니다.

```sh
npm install
npm run dev
```

최초에는 시작 시각을 HH:MM 또는 HHMM으로 입력합니다(예: 09:30 또는 0930). 유효한 숫자 네 자리(HHMM)를 입력하면 Enter 없이 첫 일정의 종료 시각 설정으로 넘어갑니다. HH:MM 형식은 Enter로 확정합니다. 빈 입력에서 Enter를 누르면 00:00으로 시작합니다. 다음 줄의 시작 시각은 앞 줄의 종료 시각을 따릅니다. 자정을 넘으면 00:00으로 이어집니다.

- 시간 입력: Space로 10분 추가, Backspace로 10분 차감, Enter로 할 일 입력.
- 첫 일정이 0분인 상태에서 Backspace를 누르면 시작 시각 수정으로 돌아갑니다. 기존 숫자를 Backspace로 지우고 수정하면 네 자리 완성 시 종료 시각 설정으로 다시 넘어갑니다.
- 전체 삭제를 누르고 확인하면 IndexedDB에 저장된 일정을 모두 비우고 최초 시작 시각 입력으로 돌아갑니다. 취소하면 기존 일정을 유지합니다.
- 일정 아래 한 줄에 전체 복사(왼쪽)와 전체 삭제(오른쪽)가 있습니다. 전체 복사는 시간·소요 시간·할 일을 줄바꿈으로 구분한 텍스트로 복사합니다.
- 빈 할 일에서 Backspace: 해당 줄 시간 선택. 다시 Backspace: 시간 초기화.
- 할 일에서 Enter: 다음 줄 시간 입력.
- 0분인 시간에서 Backspace: 이전 할 일 선택. 다시 Backspace: 이전 할 일 초기화.
- 화면 어디를 눌러도 현재 입력 모드로 돌아옵니다. 커서는 입력 끝에 고정되며 이동은 Enter와 Backspace 단축키로만 가능합니다. 내용이 있으면 Backspace는 일반 문자 삭제입니다.
- 핀치, 더블 탭, 확대·축소 단축키와 Ctrl+휠을 제한합니다. 브라우저 메뉴 또는 운영체제의 확대 기능은 웹 앱에서 차단할 수 없습니다.

모바일에서도 키보드의 공백·삭제·줄바꿈을 사용합니다. 데이터는 같은 브라우저와 주소에 저장됩니다. 브라우저 사이트 데이터를 삭제하면 계획도 삭제됩니다.

```sh
npm test
npm run build
npx playwright test
```

브라우저 테스트는 Microsoft Edge를 사용합니다. 배포는 dist 디렉터리를 HTTPS 정적 호스팅에 올리면 됩니다. PWA 설치와 오프라인은 HTTPS 또는 localhost에서 동작합니다.
